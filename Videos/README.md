# 📹 Videos do Projeto

Esta pasta contém os vídeos utilizados nas apresentações do site.

## 📁 Estrutura Recomendada:

```
Videos/
├── projeto-web/           # Vídeos do projeto HTML/CSS/JS
├── java-merlin/          # Vídeos da aplicação Java
├── mobile-kotlin/        # Vídeos do app Android
└── demonstracoes/        # Vídeos de demo gerais
```

## 🎬 Formato Recomendado:
- **Formato**: MP4 (melhor compatibilidade)
- **Resolução**: 1280x720 ou 1920x1080
- **Codec**: H.264
- **Tamanho máximo**: 50MB por vídeo (para web)

## 📝 Nomenclatura:
```
projeto-web-demo.mp4
java-merlin-interface.mp4
mobile-kotlin-funcionalidades.mp4
```

## 🔗 Integração:
Os vídeos serão incorporados nas páginas:
- `apresentacoes.html` - Abas de projetos
- `portal.html` - Seção de demonstrações
- `index.html` - Vídeos educativos (YouTube externos)
