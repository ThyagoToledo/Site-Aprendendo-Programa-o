# Bibliotecas e Frameworks Utilizados

## 🎨 Frameworks CSS

### **CSS3 Moderno**
- **Grid Layout** - Sistema de layout bidimensional para organização de conteúdo
- **Flexbox** - Layout flexível para alinhamento e distribuição de elementos
- **CSS Variables** - Reutilização de valores através de custom properties
- **Media Queries** - Design responsivo para diferentes tamanhos de tela

### **Gradientes CSS**
- **Linear Gradients** - Transições suaves de cores para headers e botões
- **Background Gradients** - Efeitos visuais em cards e seções

## 📚 Bibliotecas JavaScript

### **JavaScript Vanilla (ES6+)**
- **DOM API** - Manipulação de elementos HTML
- **Event Listeners** - Interatividade com cliques e navegação
- **Query Selectors** - Seleção eficiente de elementos DOM
- **Scroll API** - Navegação suave entre seções

### **APIs Web Nativas**
- **Intersection Observer API** - (Potencial uso futuro para animações)
- **Scroll Behavior** - Implementação de scroll suave nativo

## 🎥 Frameworks de Conteúdo

### **YouTube Embed API**
- **IFrame API** - Incorporação responsiva de vídeos
- **Player Parameters** - Configuração de autoplay e controles
- **Responsive Design** - Adaptação automática para diferentes telas

### **Font Stack Moderno**
```css
font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif
```
- **Segoe UI** - Fonte principal para Windows
- **Tahoma** - Fallback para sistemas mais antigos  
- **Geneva/Verdana** - Compatibilidade multiplataforma

## 🏗️ Arquitetura do Projeto

### **Separação de Responsabilidades**
- **HTML** (`index.html`) - Estrutura semântica
- **CSS** (`style.css`) - Apresentação visual
- **JavaScript** (`script.js`) - Comportamento interativo

### **Metodologia CSS**
- **BEM-inspired** - Nomenclatura clara de classes
- **Mobile-First** - Design responsivo progressivo
- **Component-Based** - Estilos modulares reutilizáveis

## 🌐 Tecnologias Web

### **CSS3 Avançado**
