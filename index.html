Conceitos Fundamentais do HTML

O que é HTML?

HTML (HyperText Markup Language) é a linguagem de marcação padrão para criar páginas web. É a base de toda página na internet.

  • HTML usa tags para estruturar o conteúdo
  • É interpretado pelos navegadores
  • Trabalha junto com CSS e JavaScript
  • É a fundação do desenvolvimento web

Estrutura Básica do HTML

Todo documento HTML segue uma estrutura padrão com elementos essenciais que organizam o conteúdo da página.

  • <!DOCTYPE html> - declara o tipo de documento
  • <html> - elemento raiz do documento
  • <head> - contém metadados da página
  • <body> - contém o conteúdo visível

Tags Principais

As tags HTML são os blocos de construção das páginas web. Cada tag tem uma função específica na estruturação do conteúdo.

  • <h1> a <h6> - títulos e subtítulos
  • <p> - parágrafos de texto
  • <a> - links e âncoras
  • <img> - imagens na página

Atributos HTML

Os atributos fornecem informações adicionais sobre os elementos HTML e controlam seu comportamento e aparência.

  • class - para estilos CSS
  • id - identificador único
  • src - source para imagens e mídia
  • href - destino de links

O que é um Framework?

Um framework é uma estrutura de código pré-escrita que fornece uma base sólida para desenvolver aplicações. É como um "esqueleto" que já tem a arquitetura básica pronta, permitindo que você foque na lógica específica do seu projeto.

Por que usar um Framework?

  • Rapidez no desenvolvimento: Evita reescrever código comum
  • Padronização: Mantém o código organizado e consistente
  • Segurança: Implementa boas práticas de segurança
  • Comunidade: Suporte e documentação extensiva

O que é uma Biblioteca em Programação?

Uma biblioteca é uma coleção de códigos pré-escritos que fornece funcionalidades específicas para os desenvolvedores. Diferente de um framework, que controla o fluxo da aplicação, uma biblioteca oferece ferramentas que você pode usar quando precisar.

Framework vs Biblioteca - Qual a diferença?

📚 Biblioteca
  • Você chama a biblioteca
  • Controle na sua mão
  • Exemplo: jQuery, Lodash
🏗️ Framework
  • Framework chama você
  • Controle do framework
  • Exemplo: React, Angular
